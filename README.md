# Physicocare — Physiotherapy & Rehabilitation Clinic Website

> **Move • Recover • Live Better**  
> A modern, responsive, 13-page healthcare & physiotherapy clinic website template crafted with HTML5, Tailwind CSS, custom design system tokens, and modular vanilla JavaScript.

---

## 🌟 Highlights & Features

- **13 Complete HTML Pages**:
  1. `index.html` — Home Page 1 (Classic): Clinical hero, trust stats, quick symptom checker, treatment cards, difference pillars, patient testimonials, clinician team, and booking banner.
  2. `home-2.html` — Home Page 2 (Premium Care): Editorial hero, 4-stage recovery roadmap, advanced modalities (Shockwave, AlterG, Dry Needling), and executive concierge care.
  3. `about.html` — Mission, 14-year milestone timeline, core values, leadership team bios, and board accreditations.
  4. `services.html` — Full clinical catalog with interactive category filter tabs (Spine, Sports, Post-Op, Neuro, Pediatric, Senior).
  5. `therapists.html` — 12 Board-Certified Doctor of Physical Therapy clinician profiles with specialties, credentials, education, and appointment booking.
  6. `service-details.html` — Deep dive into Spine & Disc Decompression with clinical indications, 4-phase protocol, interactive FAQ accordion, and booking modal integration.
  7. `pricing.html` — 3 tiered pricing cards, feature comparisons, and insurance/HSA/FSA reimbursement info.
  8. `contact.html` — Working contact form with demo feedback, multi-clinic branch details (San Francisco & Manhattan), hours, and emergency hotline.
  9. `login.html` — Sleek patient portal login card with password toggle, Remember Me, Forgot Password, and Google/Apple sign-in placeholders.
  10. `register.html` — Patient registration with health goal selector, password strength meter, password toggle, and HIPAA consent.
  11. `dashboard.html` — Patient portal with sidebar navigation, recovery KPI metrics, interactive daily exercise checklist with dynamic progress bar, and simulated direct therapist chat.
  12. `404.html` — Creative medical error page ("Lost Your Balance?").
  13. `coming-soon.html` — Virtual Tele-Rehab AI platform launch page with a working live countdown timer and email notify form.

## 🚀 How to Run Locally

1. **Option A: VS Code Live Server**:
   - Open this folder in Visual Studio Code.
   - Right-click `index.html` and select **Open with Live Server**.

2. **Option B: Any Local HTTP Server or Browser**:
   - Double-click `index.html` to open directly in any browser (Chrome, Edge, Safari, Firefox).
   - Or start a quick Node HTTP server:
     ```bash
     npx serve .
     ```
